### Einrichtung des Geräts

Das Gateway ordnet empfangene Funktelegramme über die EnOcean-ID des Senders einem Kanal zu. Die ID kann auf zwei Wegen in den Kanal kommen:

**Teach-In**

Im Unterkapitel **Teach-In** den Button **Teach-In starten** drücken und danach am Gerät die Lerntaste drücken (bei Tastern: eine Taste betätigen). Das Gateway erkennt die ID, mit **Ergebnis übernehmen** wird sie in die ETS geholt. Verschlüsselte Geräte werden ebenfalls so eingelernt.

**ID manuell eingeben**

Die 8-stellige EnOcean-ID im Unterkapitel **ID manuell** eintragen. Sie steht auf dem Gerät, in der Anleitung oder wird vom KO **IDs unbekannter Geräte** gemeldet. Verschlüsselte Geräte lassen sich so nicht einrichten, sie brauchen das Teach-In.

Beide Wege lassen sich jederzeit wechseln. Steht in den ID-Feldern eine ID, verwendet das Gateway diese.
