### Repeater Funktion

Level-1 = nur Nachrichten die noch nicht weitergeleitet wurden, werden 'repeated'

Level-2 = alle Nachrichten werden 'repeated'

**ACHTUNG:**

When using repeaters, care must be taken to ensure that regulatory transmitter duty cycle limits (if applicable) are not exceeded.

Level-2 repeating function should only be activated after careful study of the radio conditions! Otherwise the system function can be compromised by collisions of telegrams.
